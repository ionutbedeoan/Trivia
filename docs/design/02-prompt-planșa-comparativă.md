# Planșa comparativă — prompt și proveniență

Statut: explorare vizuală, fără aprobare. Mod de generare: instrumentul integrat `image_gen`, prin skill-ul `imagegen`. Nu este screenshot de HTML și nu conține cod de aplicație.

Planșa compară identitățile pe aceeași compoziție orientativă de Acasă. Nu înlocuiește viitoarele mockupuri S01 la dimensiunile cerute. Fonturile din raster sunt aproximări; textul, spațierea și contrastul se controlează separat în specificații. Nu se aprobă implicit ecrane prin alegerea acestei planșe.
